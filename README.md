# interactive-ramayan-app
Educational web app built using HTML, CSS, and JavaScript featuring text-to-speech, dark mode, and responsive accordion UI.

# Ramayan Learning App

An interactive Ramayan learning application with:
- Sanskrit shlokas
- Hindi explanation
- English translation
- Audio narration using Text-to-Speech
- Dark mode
- Responsive design

## Features
- Accordion based UI
- Multilanguage support
- Voice narration
- Adjustable font size
- Mobile friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project
2. Open index.html in browser
